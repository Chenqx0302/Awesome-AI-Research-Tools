# Contributing to Awesome AI Research Tools

Thank you for helping make this list better!

## What to Add

✅ **Good candidates:**
- Open-source tools with active maintenance
- Websites or services actively used by researchers
- Tools that meaningfully improve a specific part of the research workflow
- Projects with clear documentation

❌ **Please avoid:**
- Abandoned projects (no commits in 2+ years)
- Tools with no documentation or clear use case
- Paywalled tools with no free tier (unless widely used in academia)
- General-purpose LLMs (ChatGPT, Claude, etc.) — focus on research-specific tools

## Format

### GitHub Projects

```markdown
| [Project Name](https://github.com/user/repo) | ![Stars](https://img.shields.io/github/stars/user/repo?style=flat-square&color=yellow) | One-sentence description of what it does and who it's for. |
```

### Websites / Online Services

```markdown
| [Service Name](https://example.com) 🌐 | — | One-sentence description. |
```

## Category Guidelines

| Category | Include if... |
|----------|---------------|
| AI Research Agent Frameworks | The tool autonomously drives research tasks end-to-end |
| AI Coding Assistant Enhancements | It's a skill pack / plugin / config for Claude Code, Codex, Cursor, etc. |
| Literature Discovery & Management | Primary function is finding, organizing, or processing papers |
| Academic Writing & Review | Primary function is improving writing or generating reviews |
| Related Collections | It's itself an awesome-list style curated collection |

If a tool spans multiple categories, place it in the **most specific** one that fits.

## Pull Request Process

1. Fork the repo and create a branch: `add/tool-name`
2. Add your tool in the correct category, maintaining alphabetical order within each table
3. Verify all links are working
4. Submit a PR with title: `Add: [Tool Name] — [Category]`

## Description Writing Tips

- Start with a verb: "Generates...", "Automates...", "Manages..."
- Include who benefits: "Useful for researchers who..."
- Keep it under 20 words when possible
- English only in the table (Chinese notes can go in PR description)
