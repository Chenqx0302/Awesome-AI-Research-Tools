## 🤖 AI 科研 Agent 框架

> 端到端的 AI 自动化科研平台，AI 智能体自主驱动从选题到论文产出的完整科研流程。

| 项目 | Stars | 简介 |
|------|-------|------|
| [autoresearch](https://github.com/karpathy/autoresearch) | ![Stars](https://img.shields.io/github/stars/karpathy/autoresearch?style=flat-square&color=yellow) | Andrej Karpathy 开发的 AI 科研 Agent，可在单张 GPU 上自动运行 ML 实验。自动化科研的标杆项目。 |
| [AutoResearchClaw](https://github.com/aiming-lab/AutoResearchClaw) | ![Stars](https://img.shields.io/github/stars/aiming-lab/AutoResearchClaw?style=flat-square&color=yellow) | 全自动、自进化的科研流水线。输入一个想法，输出一篇论文。基于 OpenClaw 生态构建。 |
| [Research-Claw](https://github.com/wentorai/Research-Claw) | ![Stars](https://img.shields.io/github/stars/wentorai/Research-Claw?style=flat-square&color=yellow) | AI 驱动的科研平台，目标是让每个人都能成为 PI（独立研究员）。覆盖选题、实验、写作全流程。 |
| [dr-claw](https://github.com/OpenLAIR/dr-claw) | ![Stars](https://img.shields.io/github/stars/OpenLAIR/dr-claw?style=flat-square&color=yellow) | 配备多个专业 AI 助手的"超级 AI 实验室"，定位为 AI 原生科研 IDE。 |
| [Vibe-Scholar](https://github.com/Mr-Tieguigui/Vibe-Scholar) | ![Stars](https://img.shields.io/github/stars/Mr-Tieguigui/Vibe-Scholar?style=flat-square&color=yellow) | 本地优先的科研项目管理平台，支持 vibe coding 与 vibe research 工作流，完全运行在本地。 |

## 📚 文献检索与管理

> 用于发现、推荐、整理和处理学术论文的工具。

| 项目 | Stars | 简介 |
|------|-------|------|
| [zotero-arxiv-daily](https://github.com/TideDra/zotero-arxiv-daily) | ![Stars](https://img.shields.io/github/stars/TideDra/zotero-arxiv-daily?style=flat-square&color=yellow) | 根据个人 Zotero 文献库，每日自动推荐相关 arXiv 新论文。基于阅读历史的个性化论文发现。 |
| [SurveyX](https://github.com/IAAR-Shanghai/SurveyX) | ![Stars](https://img.shields.io/github/stars/IAAR-Shanghai/SurveyX?style=flat-square&color=yellow) | 学术综述论文自动生成系统，可针对给定主题自动生成结构化文献综述草稿。 |

## 贡献指南

欢迎提交 PR 补充新工具！提交前请阅读 [贡献指南](CONTRIBUTING.md)。

**添加新工具的步骤：**
1. Fork 本仓库
2. 将工具添加到对应分类
3. 遵循表格格式：`| [名称](链接) | ![Stars 徽章] | 一句话简介 |`
4. 提交 Pull Request

对于网站类或非 GitHub 工具，用 🌐 替代 star 徽章。
